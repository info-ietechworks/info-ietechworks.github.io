# IE TechWorks — SMB website launch candidate

## Preview
Open `index.html` locally. Keep all files together.

## Before publishing
- Back up your current GitHub repository.
- Review copy, service scope, and licensing requirements.
- **Review and finalize `privacy.html`** against actual business practices.
- **Test FormSubmit** using a non-sensitive inquiry and verify receipt at info@ietechworks.com; activate/verify the FormSubmit address if prompted.
- Confirm that Google Fonts, the phone number, and email are appropriate.
- Do not publish unverified testimonials, licenses, 24/7 support claims, or prices.
- Publish files to repository root while preserving `CNAME`. GitHub Pages will deploy automatically.
- Test on mobile and desktop, then connect Google Search Console and submit sitemap.xml.

## Notes
The logo is a raster crop from the approved flyer, not a vector original. The form uses third-party FormSubmit and requires a real submission test. The privacy page is a draft.
